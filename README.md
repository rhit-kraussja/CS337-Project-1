# CS337-Project-1
CS 337 Project 1 Repository

## Imports
All imports can be added using `requirements.txt`. The easiest way to install them is using a virtual environment (venv). 

## Running
All of our functions can be run using `main.py`, and then `results.py`. This should populate json files: candidates, performance, red_carpet, and results. The final results should be in the results.json file.
